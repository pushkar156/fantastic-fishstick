Module 1

Core Concepts: Cloud Computing

On-demand availability of computer system resources without direct active management by the user.

🖥️

IaaS (Infrastructure as a Service)

Provides raw virtualized computing resources, storage, and networking (e.g., AWS EC2, S3, VPC). You manage the OS, runtime, and apps.

⚙️

PaaS (Platform as a Service)

Delivers a hardware and software tools environment over the internet for app development (e.g., AWS Elastic Beanstalk, Heroku).

📦

SaaS (Software as a Service)

End-user applications hosted and operated in the cloud, completely managed by the provider (e.g., Gmail, GitHub, Microsoft 365).

🌐

Cloud Deployment Models

Public Cloud (multi-tenant on AWS/GCP), Private Cloud (dedicated internal infrastructure), and Hybrid Cloud (combines on-premise & public cloud).

Module 2

Core Concepts: DevOps & Automation

Bridging the gap between software development and IT operations to deliver value faster and more reliably.

🔄

Continuous Integration (CI)

Developers merge code changes into a central repository regularly. Automated builds and tests run to detect defects early.

🚀

Continuous Deployment (CD)

Every validated change is automatically packaged, tested, and deployed to staging or production without manual intervention.

🐳

Containerization (Docker)

Packages application code and all its dependencies into an immutable container image ensuring identical runtime behavior anywhere.

☸️

Orchestration (Kubernetes)

Automates deployment, scaling, load balancing, health monitoring, and self-healing of containerized applications.

Infrastructure

Target Environment Architecture

The complete end-to-end tooling deployed on AWS EC2.

Cloud Host

AWS EC2 (Ubuntu 22.04)

Hosts Jenkins CI controller, Docker engine, and local Minikube cluster on a t3.medium instance.

Automation Engine

Jenkins LTS

Runs pipeline-as-code via Jenkinsfile, orchestrating build, test, containerization, and rollout.

Container Registry

Docker Hub

Securely stores versioned container images tagged with unique Jenkins build numbers and :latest.

Cluster Runtime

Minikube & Kubectl

Executes rolling updates of 2 pods across a NodePort Service reachable at port 30080.
